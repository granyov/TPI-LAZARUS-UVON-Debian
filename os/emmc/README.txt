TPI LAZARUS UVON — комплект для прошивки платы целиком в eMMC
=============================================================

После записи плата загружается с внутренней памяти: прошивка, загрузчик и
Debian 13 лежат в eMMC, внешний накопитель не нужен.

Файлы
-----
  MiniLoaderAll.bin  загрузчик Rockchip, нужен только для режима MaskROM
  parameter.txt      раскладка разделов eMMC (заводская, посекторно)
  package-file       перечень для сборщиков пакетов Rockchip
  gpt.img            готовая таблица разделов, первые 34 сектора
  uboot.img          прошивка TPI, U-Boot 2024.04 v3.9 в роли UEFI
  boot.img           раздел ESP: GRUB и его конфигурация
  rootfs.img         корень Debian 13 с ядром 6.12

Раскладка eMMC
--------------
  uboot     8192 секторов @ 16384    4 МБ    прошивка
  misc      8192        @ 24576      4 МБ    настройки прошивки v3.9 (порядок загрузки)
  boot    131072        @ 32768     64 МБ    ESP  <- тип должен быть EF00
  recovery 262144       @ 163840   128 МБ    не используется
  backup    65536       @ 425984    32 МБ    не используется
  rootfs 12582912       @ 491520      6 ГБ   корень Debian
  oem      262144       @ 13074432  128 МБ   не используется
  userdata  до конца    @ 13336576  22.8 ГБ  свободно под данные

ВАЖНО про тип раздела boot
--------------------------
U-Boot соглашается грузиться с раздела только если его тип в GPT равен
C12A7328-F81F-11D2-BA4B-00A0C93EC93B (EFI System Partition, код EF00).
Таблица, которую создаёт загрузчик Rockchip из parameter.txt, присваивает
разделам собственные типы, и с ними плата с eMMC не стартует — проверено
в обе стороны на живой плате.

Поэтому после записи разделов надо положить gpt.img на смещение 0.
Он содержит ту же раскладку, но с правильным типом у раздела boot.

Консоль
-------
Последовательная консоль платы — 1 500 000 8N1: прошивка, GRUB, ядро и
вход в систему говорят на одной скорости.

Порядок установки — в docs/EMMC-IMAGE.md репозитория.
